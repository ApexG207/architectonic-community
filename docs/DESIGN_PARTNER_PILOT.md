# Design-Partner Pilot

A typical design-partner engagement is a bounded 60–90 day pilot intended to test whether Architectonic materially improves a real organizational decision or transformation problem.

## Example scope

1. Discovery and decision contract
2. Evidence/baseline assessment
3. Enterprise architecture map
4. Human-system / stakeholder analysis
5. Competing hypotheses / RCA
6. COA development and decision analysis
7. Implementation roadmap
8. Measures and prospective forecast
9. Bounded intervention
10. Outcome review and learning

## Appropriate first pilots

- Cross-functional process fragmentation
- Data/knowledge governance problems
- Strategic-plan execution gaps
- Decision latency and rework
- Organizational transformation
- AI/automation readiness
- Portfolio or program governance

Commercial scope, price, data rights, and deployment environment require a separate written agreement.
