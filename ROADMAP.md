# Public Roadmap

## Phase 1 — Community Preview
- Publish governed public package
- Establish source-available licensing
- Publish synthetic demo
- Open design-partner intake
- Launch public communications

## Phase 2 — Design-Partner Validation
- Recruit qualified design partners
- Establish decision contracts
- Freeze baselines and prospective forecasts
- Run bounded pilots
- Observe outcomes independently
- Create calibration records

## Phase 3 — Productization
- Improve onboarding and user experience
- Add governed runtime deployment patterns
- Strengthen integration, audit, and assurance
- Build repeatable implementation packages
- Establish support and maintenance model

## Phase 4 — Commercial Scale
- Enterprise licensing
- Managed services
- OEM/embedded pathways
- Government/regulated deployment pathways
- Partner ecosystem

Public roadmap items are directional and may change. Inclusion does not imply commitment, certification, or release date.
